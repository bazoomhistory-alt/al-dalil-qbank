# بنك أسئلة مراجعة أكتوبر — الدليل في البرمجة والذكاء الاصطناعي

موقع تفاعلي ثابت (Static) بالحل لمراجعة شهر أكتوبر — البرمجة والذكاء الاصطناعي — الصف الثاني (بكالوريا).

| المسار | المحتوى |
|---|---|
| `/` | الصفحة الرئيسية (اختيار النسخة) |
| `/ar/` | النسخة العربي |
| `/en/` | نسخة اللغات (إنجليزي + عربي) |

كل صفحة ملف HTML واحد مستقل (الخطوط والأيقونات جواه)، فمش محتاج أي Build ولا مكتبات.

## الرفع على GitHub
1. ادخل على github.com واعمل Repository جديد (مثلًا `al-dalil-qbank`).
2. دوس **uploading an existing file** واسحب **محتوى الفولدر** (الملفات والفولدرات اللي جواه: `index.html` و `ar` و `en` و `vercel.json` و `README.md`) مش الفولدر نفسه.
3. دوس **Commit changes**.

## النشر على Vercel
1. ادخل على vercel.com وسجّل بحساب GitHub.
2. **Add New → Project** واختار الـ Repository.
3. **Framework Preset:** Other — سيب Build Command و Output Directory فاضيين.
4. دوس **Deploy**.

أي تعديل ترفعه على GitHub بعد كده، Vercel بينشره تلقائيًا.
